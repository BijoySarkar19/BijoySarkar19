CHART SYNCHRONIZATION: 535 CONTRIBUTIONS IN 100% VISUAL HARMONY
====================================================================
- Problem diagnosed: In standard GitHub Actions, Platane/snk runs with an unauthenticated GITHUB_TOKEN that can only read public repositories (showing only ~84 public commits), while the user's real contribution graph has 535 contributions across all work.
- Solution implemented:
  - `update-profile.mjs` generates both `contributions.svg` AND `contribution-snake.svg` from the identical 371-day 535-contribution matrix.
  - Every single active day in the calendar matches the active square in the snake grid.
  - The animated cyan snake navigates the real 535-contribution landscape.
  - Redundant `snake.yml` removed to prevent unauthorized overrides.
