BIJOY SARKAR — ANIMATED GITHUB PROFILE
======================================

PACKAGE CONTENTS
- README.md
- assets/hero-banner.gif and assets/role-ticker.gif (locally hosted animations)
- assets/profile-avatar.png and three portrait photos (provided by Bijoy)
- assets/generated/*.svg (live GitHub stats, language breakdown, contribution calendar)
- .github/workflows/refresh-profile.yml (daily + push + manual refresh)
- .github/scripts/update-profile.mjs (uses GitHub REST + GraphQL APIs)
- preview.html (styled local design preview)

INSTALLATION (Windows CMD)
1. Extract this ZIP directly into your cloned profile repository folder:
   %USERPROFILE%\Desktop\BijoySarkar19
2. Open CMD in that folder and run:
   git add .
   git commit -m "Create animated navy GitHub profile"
   git push origin main
3. On GitHub, open the repository's Actions tab.
4. Run "Refresh profile data" once. It also runs daily and on future pushes.
5. If the workflow cannot push generated files, open:
   Settings > Actions > General > Workflow permissions
   and choose "Read and write permissions".

FUNCTIONALITY NOTES
- The live SVG cards and recent-repository list are generated by your own workflow.
- The workflow calls GitHub's API using the automatically provided GITHUB_TOKEN.
- The two animations and all three portrait photos are local files in this repository.
- No anime/cartoon assets are included.
