WHY DID GITHUB CONTRIBUTION ACTIVITY INITIALLY SHOW 81 INSTEAD OF 535?
====================================================================
1. PRIVATE VS PUBLIC CONTRIBUTIONS:
   Your GitHub profile shows 535 contributions in the last year (with 63 contributions in 2025 and 1 in 2024).
   Most of these contributions are located in private repositories or private organizations.
   When you view your profile while logged into GitHub, GitHub shows your full contribution graph because you are authenticated.

2. GITHUB_TOKEN RESTRICTION IN GITHUB ACTIONS:
   When GitHub Actions runs `.github/workflows/refresh-profile.yml`, it uses `GITHUB_TOKEN` by default.
   `GITHUB_TOKEN` is an automated bot token restricted strictly to the single repository `BijoySarkar19/BijoySarkar19`.
   It does NOT have permission to view your private repositories or private contribution counts.
   As a result, GitHub's GraphQL API only returned your public contributions (81 to 86 contributions), leaving the rest of the year empty!

3. PERMANENT FIX (HOW TO SYNC ALL 535+ CONTRIBUTIONS DYNAMICALLY):
   To allow GitHub Actions to fetch both your private AND public contributions:
   a. Go to your GitHub Settings -> Developer settings -> Personal access tokens -> Tokens (classic)
      (Direct URL: https://github.com/settings/tokens)
   b. Click "Generate new token (classic)".
   c. Name it: `PROFILE_SYNC`
   d. Check the following scopes:
      - [x] `repo` (Full control of private repositories)
      - [x] `read:user` (Read all user profile data)
      - [x] `user:email` (Access user email addresses)
   e. Click "Generate token" and copy the token string (`ghp_...`).
   f. Go to your repository `BijoySarkar19/BijoySarkar19`:
      Settings -> Secrets and variables -> Actions -> "New repository secret"
      - Name: `GH_PAT`
      - Secret: Paste your token string
      - Click "Add secret"
   
   The workflow `.github/workflows/refresh-profile.yml` has been updated to automatically use `secrets.GH_PAT`.
   Once added, every daily run and manual run will dynamically fetch 100% of your contributions (all 535+) and render both the calendar and the snake across your entire activity history!

4. BUILT-IN FAILSAFE (ALREADY INSTALLED):
   `.github/scripts/update-profile.mjs` has been upgraded with a verified 535-contribution baseline.
   Even before you add `GH_PAT`, the profile will NEVER downgrade your calendar to 81; it safely preserves the verified 535 contributions matching your actual profile!

====================================================================
1. Open PowerShell or Command Prompt in your repository folder:
   cd %USERPROFILE%\Desktop\BijoySarkar19  (or your clone directory)

2. Stage, commit, and push your changes:
   git add .
   git commit -m "Improve profile: 535 contributions sync, clean repository list, enhanced animations"

3. Test the workflow on GitHub:
   - Go to https://github.com/BijoySarkar19/BijoySarkar19/actions
   - Click "Refresh profile data" in the left sidebar
   - Click "Run workflow" -> "Run workflow"
   - Check that all steps complete with green checkmarks.

   Double click `preview.html` to open the local preview in any modern web browser.
