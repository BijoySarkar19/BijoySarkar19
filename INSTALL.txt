BIJOY SARKAR — ANIMATED GITHUB PROFILE (VERSION 2.0)
===================================================

PACKAGE CONTENTS
- README.md: Main GitHub profile document with responsive layouts, 535 synchronized contributions, and live game CTA.
- preview.html: Modern interactive local preview with dark glassmorphism, animations, playable live game, and multi-device responsiveness.
- assets/hero-banner.gif and assets/role-ticker.gif: Locally hosted animated navy developer banners.
- assets/cv-preview.gif: Animated preview for LaTeX CV.
- assets/portrait-casual.jpg, assets/portrait-editorial.jpg, assets/portrait-outdoor.jpg: High-res portrait gallery.

- .github/scripts/update-avatar.py: Fetches the live GitHub profile avatar and generates a circular anti-aliased PNG.
- INSTALL.txt: This setup and troubleshooting guide.


====================================================================
CHART SYNCHRONIZATION: WHY WERE THE TWO CHARTS PREVIOUSLY DIFFERENT?
====================================================================
- In the earlier version, `contributions.svg` showed 535 contributions, but `contribution-snake.svg` was generated by the default `Platane/snk` action using an unauthenticated public token that only saw 84 public commits.
- That caused the snake chart to be almost completely empty while the calendar chart was full of green dots!
- FIX APPLIED: Both charts are now 100% SYNCHRONIZED!
  - `update-profile.mjs` now generates both `contributions.svg` AND `contribution-snake.svg` from the EXACT same 535-contribution matrix.
  - Every single active green day in your calendar is now also an active green square in the snake grid.
  - The cyan animated snake now slithers and glides across your real 535-contribution landscape!


====================================================================
PLAYABLE LIVE GAME: "COMMIT HUNTER"
====================================================================
- An interactive retro-cyberpunk Snake Game has been integrated directly into `preview.html`!
- Features:
  - Collect green GitHub commit blocks (+1) and bonus golden stars (+5).
  - Aim to reach or beat your real 535 contribution streak!
  - Full keyboard controls on PC (Arrow keys, WASD, Space to pause).
  - Touch-friendly on-screen D-Pad controls (▲, ◀, ▼, ▶) for Apple iPhone, iPad, and Android mobile devices.
  - Sound synthesis via Web Audio API with a toggle button (🔊 / 🔇).
  - High-score memory saved locally in browser storage.

====================================================================
HOW TO PUSH AND RUN
====================================================================
1. Open PowerShell or Command Prompt in your repository folder:
   cd %USERPROFILE%\Desktop\BijoySarkar19  (or your clone directory)

2. Stage, commit, and push your changes:
   git add .
   git commit -m "Synchronize contribution snake, add Commit Hunter game and SEO suite"
   git push origin main

3. Test the workflow on GitHub:
   - Go to https://github.com/BijoySarkar19/BijoySarkar19/actions
   - Click "Refresh profile data" -> "Run workflow"

4. Preview locally anytime:
   Double click `preview.html` to open the local preview and play the game in any modern browser!
